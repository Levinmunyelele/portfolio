# Levin Munyelele | Developer & Data Scientist Portfolio

This is a personal portfolio website for Levin Munyelele showcasing projects, skills, blog posts, and contact details.

## 📂 Folder Structure
```
├── index.html         # Main HTML file
├── style.css          # External styles
```

## 🚀 Features
- Clean, responsive design using Tailwind CSS
- Blog section with project writeups
- Downloadable CV link
- Theme switcher (light/dark)
- Skills section with badges
- Contact form (via Formspree)
- Mobile-friendly navigation

## 🛠️ Technologies Used
- HTML5 + Tailwind CSS
- JavaScript
- AOS animations
- Font Awesome Icons

## 📝 Customize
You can edit `index.html` to:
- Add new projects/blogs
- Change skills
- Update contact form email

## 📦 Deployment
You can deploy this easily with **GitHub Pages**:
1. Push to your GitHub repository
2. Go to **Settings > Pages**
3. Select `main` branch and `/root` folder

Your site will be live at:
```bash
https://yourusername.github.io/portfolio
```
